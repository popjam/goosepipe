Encyclopedia / Memory
Games

Memory

Watch the pattern of arrows that appears above your Tamagotchi, then repeat it with the buttons. Each round the pattern is one arrow longer.

Playable

Can be drawn when your Tamagotchi becomes an adult or at any later stage. Cannot start while sleeping or sick.

On screen

Buttons

ButtonAction
ALEFT arrow.
BRIGHT arrow.
CUP arrow.
DDOWN arrow. D does not stop this game.

How to play

Clear 20 rounds to win. The first pattern has 2 arrows and every round adds one more. The arrows appear one at a time, then disappear; repeat them in the same order. Each correct round shows GOOD with your Tamagotchi cheering. One wrong arrow ends the game, and so does waiting more than 3 seconds between presses.
