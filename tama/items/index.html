Browsing your items

  • Games → Items lists what your Tama owns, one item per page. Meal and Snack work the same way.
  • A and B page through the list. The bottom-left number (for example X1) is how many you own; the bottom-right number is the page.
  • Using items with C is coming soon. Every Tama starts with one of each starting item; more can be bought at the Corner Shop with points.
  • Items belong to your Tama: a new generation starts again with only the starting items.
