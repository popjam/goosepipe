Reading a list

  • A moves back; B moves forward; C selects; D returns to the parent menu.
  • Long names wrap onto a second line. Lists scroll to keep the selected row visible.
  • Entries that are not available yet stay on the list when selected.
  • The top and bottom icon strips stay visible while browsing.
  • Meal, Snack and Items show one item per page instead of a list. A and B turn the page; the page number is in the bottom-right corner.
